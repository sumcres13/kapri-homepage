# KAPRI website — single-page version

Open `index.html` to view the complete site. Home, About, Shop Access, and Reservation are sections of one page. The header, calls to action, and footer link to those sections.

The About section places the company overview below its heading, then pairs the representative's complete portrait with her message. A warm-colored identity card sits mostly below the portrait so the photo stays visible. Values cards appear in a white band, followed by a company-information table in a warm cream band. The shop section has original orange spice-flower and arch vector art over its pale background. Both shop profiles place the restaurant story and practical information beside a photo gallery with selectable thumbnails; Godawari has its description on the left and gallery on the right at desktop sizes. The reservation section uses a light black tint over a supplied restaurant interior photo; both white booking cards are shown together, with complete storefront photos, gently rounded booking and delivery choices, and the original links. The SNS section uses a black photo tint, and the footer has a solid terracotta-orange background with white text. Mobile content is center aligned.

The Japanese/English switch changes the page language. SNS links for LINE and both Instagram accounts sit above the footer. Both Instagram buttons use the supplied logo image. Images are in `assets/`; the local BudouX parser is in `vendor/`. No build step or external JavaScript dependency is required.

The footer uses a solid orange-brown color with white text. The restaurant information, photos, contact details, and external links were provided by the owner. The company registered address was not supplied, so no registered address is shown.
